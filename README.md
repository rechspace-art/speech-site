# речь. — сайт тренера по технике речи

Статический сайт (один `index.html`, без сборки и сервера). Публикуется через GitHub Pages.

## Структура
- `index.html` — весь сайт
- `assets/` — изображения (практика, форматы, фото «обо мне»)
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages

## Как редактировать положение картинок в разделе «Практика»
Открыть сайт с `#edit` в адресе (или нажать Alt+E) — появится панель редактора.
